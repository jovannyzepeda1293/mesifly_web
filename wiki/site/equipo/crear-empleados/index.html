    Cómo creo empleados

    Dar acceso a tu equipo con usuario y contraseña, y compartirles el enlace para entrar.

    Dirección en la app: app.mesifly.com/tu-negocio/employees

    Para quién es #

    Para el dueño. Los empleados atienden pedidos sin tocar la configuración del negocio.

    Antes de empezar #

    Define para cada empleado un usuario (sin espacios; letras, números, punto, guion y guion bajo) y una contraseña segura (8 a 16 caracteres con mayúscula, minúscula, número y símbolo).

    Pasos: crear #

    1. Entra a Empleados (barra de arriba) y pulsa Nuevo empleado.
    2. Llena Usuario, Contraseña y Confirmar contraseña.
    3. Pulsa Crear empleado.

    Pasos: compartir el enlace de acceso #

    1. En Empleados pulsa Copiar enlace de inicio de sesión (dirá ¡Copiado!).
    2. Envía ese enlace a tu empleado junto con su usuario y contraseña. Verá «Inicio de sesión de empleados».

    Pasos: editar o eliminar #

    1. Editar: cambia el usuario o la contraseña. Si dejas la contraseña en blanco se conserva la actual. Pulsa Guardar cambios.
    2. Eliminar: confirma «¿Seguro que deseas eliminar este empleado? Esta acción no se puede deshacer.» con Sí, eliminar.

    Qué verás #

    «Empleado creado.», «Empleado actualizado.» o «Empleado eliminado.». Si aún no tienes empleados verás «Sin empleados.».
