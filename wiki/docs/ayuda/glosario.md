# Glosario

| Término | Qué significa |
|---|---|
| **Restaurante / sucursal** | Cada negocio que das de alta. Tiene su menú, enlace, horario, empleados y Telegram. Cuenta como un menú de tu plan. |
| **Dueño** | Quien contrata y administra la cuenta. Ve todo. |
| **Empleado** | Persona con acceso limitado que atiende pedidos. Lo crea el dueño. |
| **Comensal / cliente** | Quien pide desde el enlace del menú. No se registra. |
| **Menú digital / menú público** | La página con tus categorías y platillos que ven tus clientes. |
| **Enlace del menú** | La dirección `dominio/nombre-del-negocio` que compartes. |
| **Categoría** | Grupo de platillos (Tacos, Bebidas…). |
| **Platillo** | Un producto del menú, con nombre, precio, descripción y foto. |
| **Estado del platillo** | **Activo** (visible), **Inactivo** (oculto, se conserva) o **Archivado**. |
| **Pedido** | Orden que el cliente confirma desde el menú. |
| **Pendiente / Atendido** | Estados de un pedido: por atender y ya resuelto. |
| **Tema** | Conjunto de colores del menú (Clásico, Océano, etc.). |
| **Plan / menús** | Cuántos restaurantes puedes tener activos; cada uno cuesta $5 USD al mes. |
| **Prueba gratis** | Los primeros 14 días de la primera alta, sin cobro. |
| **Telegram** | App de mensajes por donde te avisamos de cada pedido nuevo. |
| **Vista previa** | Cómo verá tu cliente el menú, sin salir del panel. |
