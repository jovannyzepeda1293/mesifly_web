# Variables de esta ayuda

Valores que se repiten en varios artículos. Si cambian, **busca y reemplaza** en toda la carpeta `docs/ayuda/`. Al reutilizar la wiki en otro proyecto, empieza por aquí.

| Variable | Valor actual | Dónde sale |
|---|---|---|
| Nombre del producto | Mesifly | Todos |
| Dominio del enlace de menú | `[POR CONFIRMAR: dominio oficial]` (el enlace tiene la forma `dominio/nombre-del-negocio`) | Compartir el menú, FAQ |
| Precio | $5 USD al mes por restaurante (sucursal) | Suscripción, plan, FAQ |
| Prueba gratis | 14 días, solo en la primera alta | Suscripción, FAQ |
| Máximo de menús por plan | 30 | Plan y menús |

| Formato de teléfono | Internacional, ejemplo `+5215512345678` | Crear cuenta, restaurante |
| Imágenes de platillos | JPG, PNG o WebP, hasta 8 MB | Platillos |
| Temas de color | Clásico, Nocturno, Océano, Bosque, Atardecer, Realeza, Rosa, Monocromo, Cítrico, Pastel | Restaurante |

| Canal de avisos de pedidos | Telegram | Pedidos, FAQ |
